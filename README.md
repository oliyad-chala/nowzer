# Simple school Website  
This is a personal portfolio website built with HTML, CSS, and JavaScript. It features a modern and responsive design, showcasing projects and skills in a user-friendly way.
## Features  
.Responsive design for mobile and desktop  
.Smooth animations and transitions  
.Dark and light mode
## Technologies Used  
- HTML  
- CSS (Flexbox, Grid, Animations)  
- JavaScript (DOM Manipulation)
